## Full Stack ToDo App

[ made for practice ]

A minimal full stack todo app with CRUD functionalities, with proper Auth handling with JWTs and storage of user data and task data in `users.json` and `todos.json`

#### Tech used:

- React
- Tailwind
- Express
- JWT (for auth)
- .json files (for simualating database)

**Note**: create your own JWT_SECRET in .env

#### How to run locally:

- `git clone https://github.com/Swayam226/fullstack-todo`
- `cd frontend`
- `npm install`
- `npm run dev`

---

- `cd backend`
- `npm install`
- `node index.js`
